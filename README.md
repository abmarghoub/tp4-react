#TP 4 : Projet de synthèse React – To-Do List interactive ou Blog simple

## 1. Objectif du TP 
- L'affichage d'une liste d'articles.  
- La consultation détaillée d'un article.  
- La modification d'un article existant.  
- L'utilisation du **routage interne** avec React Router.  
- La stylisation de l'application avec **Bootstrap**.  
- La préparation de l'application pour un **déploiement en ligne**.

---

## 2. Architecture du TP

### 2.1 Stack technologique

| Composant        | Technologie          | Utilisation                                                                 |
|-----------------|-------------------|----------------------------------------------------------------------------|
| Frontend        | React.js           | Création des composants et pages                                           |
| Routage         | React Router DOM   | Navigation interne entre les pages                                         |
| CSS             | Bootstrap          | Stylisation responsive et composants visuels                              |
| Build & Déploiement | npm, Netlify/Vercel | Construction du projet et mise en ligne                                   |
